# Blue Hour AR

[Online demo](https://blue-hour-ar.vercel.app/blue-hour/?look=reference)

Run `npm ci` and `npm run dev`, then open `/blue-hour/?look=reference` at the local address shown by Vite. Allow camera access. Smile for rain and laugh for fireworks. During fireworks, shake your head to scatter sparks or look up once sparks gather above your head.

Run `npm run build` for the production build. See [diagnostics](docs/blue-hour-diagnostics.md) for performance and expression tools.
